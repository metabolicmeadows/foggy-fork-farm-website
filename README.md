# Foggy Fork Farm — Redesign Concept

A polished single-page redesign demo for Foggy Fork Farm LLC, a small family farm in Floyd, Virginia that raises registered Miniature Nubian dairy goats holistically. Built as a sales pitch for Quickset Studio.

## Run it
Open `index.html` directly in any browser — no build step, no server required.

## Stack
- Single static `index.html`
- Tailwind CSS via CDN (JIT)
- Anton (display/headlines) + Inter (body) from Google Fonts
- Vanilla JS for scroll reveal animations and nav state

## Design direction
Earthy, holistic, pastoral — "small farm, deep roots." Warm parchment palette with olive sage (#6B7A3A) and terracotta (#C4733A) accents.
